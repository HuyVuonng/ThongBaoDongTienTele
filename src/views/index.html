Cấu Hình API Token SePay

⚡ Hướng dẫn 3 bước lấy API Token (Miễn phí 100%):
  1. Đăng nhập my.sepay.vn & kết nối STK ngân hàng của bạn.
  2. Vào mục Tích hợp / API Key (hoặc Company Settings > API Access).
  3. Tạo & Copy API Token, dán vào ô bên dưới rồi bấm Lưu!
Token này được lưu an toàn trên máy chủ của bạn để tự động quét giao dịch.
Tự động đồng bộ giao dịch (Auto-Sync)
